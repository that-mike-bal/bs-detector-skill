# Free Tier Limit: Recommendation

## 1. Recommendation
Raise the free-tier project limit from 3 to 5.

## 2. Background on the request
Leadership asked for a one-page recommendation on whether to raise the free-tier limit from 3 projects to 5. The recommendation should cover the expected effect on conversion and the main risk. This section restates that request so readers have the context for what follows.

## 3. Expected effect
Free users who hit the 3-project limit convert to paid at 11%, versus 2% for those who don't. Raising the limit could reduce the number of users who hit it.

## 4. Risk
Fewer users would hit the limit, so fewer would see the upgrade prompt.
