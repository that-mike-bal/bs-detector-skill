# Sunsetting the Legacy Reports Module

You asked for a one-page recommendation on whether we should sunset the legacy reports module. You said you need a yes or no answer, along with the main reason behind it. This document provides that recommendation.

As background, the legacy reports module is the older reporting tool that some customers still use. You asked whether we should sunset it, meaning retire it and move customers to the new analytics product. The question was whether to do this, and you wanted the main reason for the answer.

To restate the request: the goal of this document is to give a clear yes or no on sunsetting legacy reports and to explain the main reason.

Recommendation: yes. Only 3% of active accounts opened legacy reports in the last 90 days, and every report they use exists in the new analytics product. Keeping it costs about one engineer's time a quarter in maintenance.
